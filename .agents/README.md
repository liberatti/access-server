# Agent Configurations

This directory contains localized rules and skills for agentic AI workflows in this repository.

## Structure

- **[/rules](file:///home/liberatti/workspace/github.com/liberatti/access-server/.agents/rules)**: Rules injected into the agent's context.
  - [context-control.md](file:///home/liberatti/workspace/github.com/liberatti/access-server/.agents/rules/context-control.md): Context minimization and diff minimization rules.
  - [ui-ux.md](file:///home/liberatti/workspace/github.com/liberatti/access-server/.agents/rules/ui-ux.md): Angular Material UI/UX rules, updated for the modern, light, and minimalist style.
- **[/skills](file:///home/liberatti/workspace/github.com/liberatti/access-server/.agents/skills)**: Custom skills.
  - [minimal_code_editor](file:///home/liberatti/workspace/github.com/liberatti/access-server/.agents/skills/minimal_code_editor/SKILL.md): Directives for direct, surgical code editing with Flake8 compatibility.
